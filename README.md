# Kolkra-NG

The next generation of Kolkra, The Coral Reef's custom utility bot.

- **Github repository**: <https://github.com/m1n0rm1n3r/Kolkra-NG/>
- **The Coral Reef**: <https://discord.gg/coralreef>

Kolkra is a custom discord.py bot built for The Coral Reef.
This repository is mainly intended for transparency and education purposes, though contributions are welcome!

> [!IMPORTANT]
> This bot used to operate within the Splatfest server, but was since migrated to The Coral Reef.
> If you had data that wasn't tied specifically to Splatfest in the bot while it was running in Splatfest, it should carry over to TCR. Please contact @/m1n3r_spl if you have any questions or issues.
